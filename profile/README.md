<h1 align="center">Broton: your bro for Proton</h1>

<p align="center">
  <b>Small Thunderbird add-ons that smooth out the rough edges of Proton Mail.</b>
</p>

---

Proton Mail is great for privacy. Using it day to day in Thunderbird, though, comes with a few annoyances:

* All Mail shows every message, but deleting or moving one there doesn't do what you expect, and you can't see which folder it really lives in.
* Your Sieve filters live in the web app, so every small rule change means signing in to the browser again.
* Sending from a SimpleLogin alias means creating and copying reverse aliases by hand, and one slip reveals your real address.

Bro for Proton is here to help. Broton is a small family of Thunderbird add-ons, each fixing one of these annoyances so you get Proton's privacy with Thunderbird's comfort.

## The add-ons

<table>
  <tr>
    <td width="96" align="center"><img src="images/all-mail-buddy-128.png" alt="All Mail Buddy icon" width="72"></td>
    <td>
      <h3><a href="https://github.com/Broton-Your-bro-for-Proton/All-Mail-Buddy">All Mail Buddy</a></h3>
      Shows the real folder and labels of every message in Proton's All Mail folder, and makes delete, move, archive and junk act on the message in its real folder.<br>
      <sub>Works with Proton Mail Bridge</sub>
    </td>
  </tr>
  <tr>
    <td width="96" align="center"><img src="images/sieve-buddy-128.png" alt="Sieve Buddy icon" width="72"></td>
    <td>
      <h3><a href="https://github.com/Broton-Your-bro-for-Proton/Sieve-Buddy">Sieve Buddy</a></h3>
      Edit Sieve filters right in Thunderbird: a server-aware editor, rules from a mail in two clicks, a simulator and a version history. Comes with an optional Docker service with a REST API and an MCP server.<br>
      <sub>Works with Proton Mail, any ManageSieve server and JMAP for Sieve</sub>
    </td>
  </tr>
  <tr>
    <td width="96" align="center"><img src="images/alias-buddy-128.png" alt="Alias Buddy icon" width="72"></td>
    <td>
      <h3><a href="https://github.com/Broton-Your-bro-for-Proton/Alias-Buddy">Alias Buddy</a></h3>
      Send as a SimpleLogin alias to normal addresses. Creates and fills in reverse aliases for you and blocks messages that would reveal your real address.<br>
      <sub>Works with SimpleLogin</sub>
    </td>
  </tr>
</table>

## Status

All three add-ons have stable releases on GitHub. Each repository explains how to install it.
